# Development

The canonical interface and financial/interchange engine is `app/assets/index.html`. Bank logos and the currency font are embedded for offline use. The wrapper retains the original `vault` SharedPreferences name and `data` key, so signed app updates preserve existing records.

The active Android build is `native/build.gradle`, using Gradle 8.11.1, Android Gradle Plugin 8.9.2, Java 17, compile/target SDK 34, build-tools 35.0.0, and minimum Android 26. `scripts/gradle.ps1` downloads Gradle from its official distribution and verifies the pinned SHA-256 in `tools/gradle-source.json`. Runtime dependencies are pinned in `native/gradle.lockfile`; update them deliberately with `-WriteLocks`. Google Play services authorization is version 22.0.0. Gradle packages native resources, dependency manifests and DEX files. `app/apktool.yml` supplies version information; the build does not use Apktool or decompiled smali.

Edit the wrapper in `native/src/app/depositly/mobile/MainActivity.java`, Google authorization and Drive transport in `native/src/app/depositly/mobile/cloud/`, and payout reminders in `native/src/app/depositly/mobile/reminders/`. The wrapper prevents remote navigation and subresource requests; native bridges are exposed only to the packaged interface. Google authorization uses Google's native account/consent UI.

Run `scripts/test.ps1` for financial, display, import/export, reminder, renewal, cloud restore and CI-version regression checks. Run `scripts/gradle.ps1 -Tasks @('testReleaseUnitTest')` for native Drive transport tests. Both are release gates in GitHub Actions. Use `scripts/build.ps1` for a signed APK, or add `-Unsigned` for a build without signing credentials. Every signed build verifies package/version, ZIP alignment and the original signing certificate.

For each app update, run `scripts/bump-version.ps1` to increase the visible Build number and Android code together. It considers the last local `dist/build-info.json`; pass `-PreviousBuildInfoPath` when a published build has a higher code. The bump updates the configuration, interface labels, documentation and APK filenames. Signed builds reject a reused or older version against available local and downloaded release metadata; CI checks the visible version against its previous release too. Unsigned verification rebuilds can reuse the same version.

Drafts, temporary tests, downloaded Gradle tools, project caches and compiler output use `Z:\WORK DIRECTORY\Depositly` locally. Override the parent with `DEPOSITLY_WORK_DIRECTORY`; CI uses `RUNNER_TEMP`, and machines without the Z: work directory use system temporary storage. `DEPOSITLY_GRADLE_CACHE` can still override the dependency cache. The Gradle build directory is supplied through `depositlyBuildDirectory`. Final release APKs and the version baseline stay in `dist/`. Dependencies require internet access on the first build. Bootstrap can install the SDK platform/build-tools with `scripts/bootstrap.ps1 -InstallSdk`.

See [Google Drive setup](google-drive.md) for the supplied OAuth client, signing fingerprint, scope and test-user configuration. Actual Google sign-in, account switching, permissions, offline retry and restoration across phones require Android device testing. Notification delivery also depends on Android battery/alarm rules.
